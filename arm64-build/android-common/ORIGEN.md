# Componente oficial Android Common

Origen: https://github.com/aosp-mirror/kernel_common/tree/e148935a1d484f8a9a0742acbb22ca966f8067df
Rama observada: android15-6.6. Se conserva el código y los avisos GPL-2.0 de Google (2025).
